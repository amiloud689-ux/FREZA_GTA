FREZA OPEN WORLD — مشروع Android أصلي (Java)، بدون Godot.

ماذا يحتوي؟
- لعبة 2D من منظور علوي للمدينة.
- تحريك اللاعب بأزرار اللمس.
- سيارة يمكن دخولها والخروج منها وقيادتها.
- زر إطلاق تجريبي ومقذوفات.
- مدينة مبنية برمجياً ولا تحتاج ملفات رسومية خارجية.

مهم: هذا نموذج أولي 2D وليس GTA 3D. لم أرفق APK جاهزاً لأن بيئة البناء الحالية لا تحتوي Android SDK. أضفت إعداد GitHub Actions ليُبنى APK في السحابة.

طريقة استخراج APK من الهاتف:
1. فك ضغط FREZA_ANDROID_NATIVE.zip.
2. افتح github.com وسجّل الدخول أو أنشئ حساباً.
3. أنشئ Repository جديداً باسم FREZA-OPEN-WORLD.
4. ارفع محتويات المجلد إلى المستودع (لا ترفع مجلد FREZA_ANDROID_NATIVE كطبقة إضافية؛ ارفع الملفات والمجلدات التي بداخله مباشرة).
5. افتح تبويب Actions، ثم اختر Build FREZA APK، واضغط Run workflow.
6. انتظر حتى تنتهي المهمة بنجاح.
7. افتح نتيجة التشغيل، وانزل إلى Artifacts، وحمّل FREZA-OPEN-WORLD-APK.zip.
8. فك ضغطه وستجد app-debug.apk. ثبّته على هاتف Android.

ملاحظة: نسخة Debug للتجربة. للنشر على Google Play يلزم إنشاء توقيع Release ومفتاح توقيع خاص.
